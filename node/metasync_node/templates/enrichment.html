Enrichment

Look up an artist, album or track and see everything this node knows about it — and how it knows it: which values are your own library's, which came from the network, and what this node has verified itself. Support is shown the way §9 shows it everywhere, this page included: as a coarse bucket (none, 1-2, 3+) — this page shows no exact support count of its own, and the node keys of whoever asserted a value are never shown to any user, not even here. A few orderings inherited from the merge itself are the named exception, listed in DATA.md §20. Viewing never promotes anything into your library, and nothing this page shows is sent anywhere. Scope is the one choice that matters: “ask the network” runs this node's normal ask — it can bring new answers into the local cache and schedule verification of them, exactly as any ask does — while “only what this node knows” is a pure read of what the node already holds: no ask, no fetches, no verification.
