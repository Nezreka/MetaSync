Pools

A pool is a network this node exchanges data with; SIN is one pool. Normally the pool key is entered in SoulSync, handed to MetaSync over the protected local connection, and exchanged here for a short-lived access token. This page is therefore mainly connection status. The manual key form remains available below as a labelled fallback.

A normal node can only push its weekly report and pull index/playlist data. The admin role is only for Boulder's official MetaSync, which publishes the shared playlist data — user nodes never publish.
